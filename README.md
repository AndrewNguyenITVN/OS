## 📌 Introduction  
This repository contains lab exercises and practice materials for the **Operating System** course offered by **CICT – Can Tho University**. The course introduces fundamental concepts of modern operating systems and provides hands-on experience in working with OS components such as process management, memory management, file systems, and concurrency.

The practice sessions are designed to strengthen understanding of OS internals through programming assignments, shell usage, and kernel-level exploration.

## 📌 Notes  
- This practice content is for educational purposes only.  
- Students are encouraged to test all programs in a Linux environment.
